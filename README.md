# YourWeek

Личный недельный планер без регистрации и облачной синхронизации. Первый срез: текущая неделя, быстрый ввод задач, три пустых списка «Когда-нибудь» и сохранение в IndexedDB.

## Запуск

Нужны Node.js 24+ и pnpm 12.3.4.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте адрес localhost, показанный Vite. Enter или «Добавить» сохраняет задачу, Escape отменяет ввод. Пустой ввод ничего не создаёт.

Для самостоятельного статического размещения:

```sh
pnpm build
pnpm preview
```

`dist/` содержит только статические файлы; отдавайте их с HTTPS или localhost. Preview предназначен для локальной проверки, не для production. `file://` не поддерживается. Не требуются API или серверная база. Офлайн-оболочка будет добавлена отдельным тикетом; сейчас повторный запуск требует доступного сервера статики.

## Данные

Задачи хранятся только в IndexedDB этого origin и браузерного профиля. Смена адреса, порта или профиля не переносит их. Очистка данных сайта может удалить план, а приватный режим не гарантирует долговременного хранения. Используйте одну рабочую вкладку. Резервные копии будут добавлены отдельным тикетом. Приложение не отправляет пользовательские данные и не загружает внешние шрифты, аналитику или ссылки из задач.

При ошибке записи задача не появляется на доске, сообщение явно указывает несохранённость, а введённый текст остаётся для повторной попытки. Недоступная база не заменяется временным хранением.

## Проверки

```sh
pnpm typecheck
pnpm lint
pnpm format:check
pnpm exec playwright install chromium
pnpm test:browser
```

Браузерный набор собирает статическое приложение и запускает локальный preview. Тесты используют настоящий Chromium/IndexedDB: создание и порядок, пустой ввод и Escape, перезагрузка, закрытие и открытие постоянного профиля, смена часового пояса, отмена настоящей транзакции после успеха запроса, раскладки 360/1200 px. Все данные синтетические; личные CSV не нужны.

## Границы модулей

- `src/model.ts` — задачи, списки и взаимоисключающее размещение по дате или списку.
- `src/storage.ts` — `PlannerStorage.open/readWeek/readLists/createTask`, схема IndexedDB v1, подтверждение записи только после завершения транзакции. Новые версии схемы должны мигрировать данные без удаления базы.
- `src/calendar.ts` — локальные календарные даты без UTC и расчёт недели.
- `src/board.ts` — отображение и быстрый ввод; получает данные и асинхронную команду создания, не открывает базу.
- `src/main.ts` — композиция хранения и доски. Будущий редактор должен быть отдельным модулем, не частью хранилища или недельного рендера.

Версии инструментов закреплены по npm registry; TypeScript 6.0.3 выбран вместо latest 7.0.2 из-за ограничения совместимости typescript-eslint `<6.1`. Конфигурация сверена с Context7 документацией Vite, Playwright, typescript-eslint и Prettier.
