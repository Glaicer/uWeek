# CSV-импорт YourWeek

Файл загружается на сервер YourWeek в аккаунт вошедшего пользователя. Проверка и preview не меняют базу; подтверждение повторно проверяет исходный файл и атомарно добавляет задачи, списки и SHA-256 отпечаток исходных байтов. Ошибка не оставляет частичный импорт.

Отпечаток, дата и счётчики сохраняются в `import_history` с уникальной парой `(user_id, fingerprint)`. Повтор того же файла, в том числе одновременные подтверждения или повтор после удаления импортированных задач, добавляет ноль. Другой пользователь может импортировать те же байты независимо. Изменённые байты, включая BOM/переносы строк, — новый файл, не merge. Сам CSV не сохраняется: в задачах остаются исходные значения и происхождение.

## Формат

- UTF-8 с необязательным BOM; запятая; LF/CRLF; CSV-экранирование кавычек, запятых и многострочного текста.
- Ровно шесть известных заголовков в любом порядке: `Date,Task,Notes,Checklist,Completed,List`. Неизвестные, отсутствующие и повторные заголовки отвергаются.
- Не более 5 MiB и 100 000 логических записей. Полностью пустые записи игнорируются с отдельным счётчиком. Номера в ошибках относятся к логическим CSV-записям, включая заголовок, не физическим строкам.
- Любая ошибка блокирует весь импорт; исправьте исходный файл и выберите заново. Частичного импорта нет.

## Поля

| Поле      | Значение                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------- |
| Task      | Непустое название; рабочее значение обрезается по краям, исходное сохраняется                       |
| Date      | Корректная календарная дата YYYY-MM-DD или пусто; будущие годы сохраняются полностью                |
| Notes     | Буквальный текст, Unicode, кавычки и переносы; HTML/XML и URL не исполняются и не загружаются       |
| Completed | TRUE/FALSE, без учёта регистра и внешних пробелов; пустое значение — ошибка                         |
| List      | Только для записи без даты; существующие имена сопоставляются без учёта регистра и внешних пробелов |
| Checklist | Только пустое поле: сериализация непустого чек-листа не подтверждена и блокирует импорт             |

Дата и список одновременно — ошибка. Без даты и списка задача идёт в `Inbox` (список создаётся при необходимости). Без даты с именем списка — в этот список, новый создаётся при подтверждении. Датированная задача требует пустого List.

Порядок исходных записей задаёт порядок в каждом контейнере; импорт добавляется после существующих сохранённых задач. Виртуальные вхождения серий остаются после сохранённых задач, включая импортированные: ради порядка импорта исключения серий не создаются (решение владельца 2026-11-16). Одинаковые строки внутри файла — отдельные задачи с разными ID и номерами записей. Все шесть исходных значений и номер записи сохраняются как неизменяемое происхождение; редактирование рабочих полей их не переписывает.

## Интерфейс

Импорт доступен из меню (⋯) → `Import from Tweek` на отдельной странице настроек. `Choose CSV file` — оформленная кнопка; нативное поле выбора файла скрыто. Интерфейс и ошибки — на английском.

Preview показывает число задач, выполненность, диапазон дат, задачи без даты, новые списки, точные повторы, пустые записи и первые 20 задач. Итог показывает точное число добавленных задач и списков; ссылка `Back to planner` возвращает к выбранной неделе. До подтверждения можно уйти со страницы без изменений.

Старые незавершённые задачи импортируются с исходными датами; при следующем чтении планера к ним применяется обычный перенос на сегодня по часовому поясу пользователя. Исходная дата в происхождении не меняется.

## Ограничения перехода

CSV не содержит цвета или достоверных правил повторения. Повторяющиеся названия не восстанавливают серии; после последней выгруженной даты новые вхождения не создаются. Отсутствующие списки и их задачи невозможно восстановить из этого файла — создайте их вручную. Непустой Checklist, другая кодировка или разделитель не поддерживаются. CSV не является полной резервной копией. Перенос старой JSON-копии YourWeek не входит в эту версию.
