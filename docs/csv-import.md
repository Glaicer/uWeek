# CSV-импорт YourWeek

Файл выбирается локально и не отправляется по сети. Проверка и preview не меняют базу; подтверждение атомарно добавляет задачи, списки и SHA-256 отпечаток исходных байтов. Ошибка не оставляет частичный импорт. Сохранённый отпечаток включён в JSON-копию: повтор после восстановления добавляет ноль задач. Изменённые байты, включая BOM/переносы строк, — новый файл, не merge.

## Формат

- UTF-8 с необязательным BOM; запятая; LF/CRLF; CSV-экранирование кавычек, запятых и многострочного текста.
- Ровно шесть известных заголовков в любом порядке: `Date,Task,Notes,Checklist,Completed,List`. Неизвестные, отсутствующие и повторные заголовки отвергаются.
- Не более 5 MiB и 100 000 логических записей. Полностью пустые записи игнорируются с отдельным счётчиком. Номера в ошибках относятся к логическим CSV-записям, включая заголовок, не физическим строкам.
- Любая ошибка блокирует весь импорт; исправьте исходный файл и выберите заново. Частичного импорта нет.

## Поля

| Поле      | Значение                                                                                            |
| --------- | --------------------------------------------------------------------------------------------------- |
| Task      | Непустое название; рабочее значение обрезается по краям, исходное сохраняется                       |
| Date      | Корректная календарная дата YYYY-MM-DD или пусто; будущие годы сохраняются полностью                |
| Notes     | Буквальный текст, Unicode, кавычки и переносы; HTML/XML и URL не исполняются и не загружаются       |
| Completed | TRUE/FALSE, без учёта регистра и внешних пробелов; пустое значение — ошибка                         |
| List      | Только для записи без даты; существующие имена сопоставляются без учёта регистра и внешних пробелов |
| Checklist | Только пустое поле: сериализация непустого чек-листа не подтверждена и блокирует импорт             |

Дата и список одновременно — ошибка. Без даты и списка задача идёт во «Входящие» (список создаётся при необходимости). Без даты с именем списка — в этот список, новый создаётся при подтверждении. Датированная задача требует пустого List.

Порядок исходных записей задаёт порядок в каждом контейнере; импорт добавляется после существующих задач. Одинаковые строки внутри файла — отдельные задачи с разными ID и номерами записей. Все шесть исходных значений и номер записи сохраняются как неизменяемое происхождение; редактирование рабочих полей их не переписывает.

Preview показывает число задач, выполненность, диапазон дат, задачи без даты, новые списки, точные повторы, пустые записи и первые 20 задач. Итог показывает точное число добавленных записей; выбранная неделя не меняется.

## Ограничения перехода

CSV не содержит цвета или достоверных правил повторения. Повторяющиеся названия не восстанавливают серии; после последней выгруженной даты новые вхождения не создаются. Отсутствующие списки и их задачи невозможно восстановить из этого файла — создайте их вручную. Непустой Checklist, другая кодировка или разделитель не поддерживаются. Полная JSON-копия, а не CSV, предназначена для последующего переноса между профилями.
