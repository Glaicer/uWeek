# Приёмка YourWeek MVP

Дата: 2026-10-06. Исходная интеграционная база: `f5540cd`. Только локальная приёмка; публикация, push и деплой не выполнялись. Спека и статусы тикетов не менялись.

## Окружение и воспроизводимость

- Fedora Linux x86_64, ядро 7.2.7-200.fc44.x86_64.
- AMD Ryzen 7 5800H: **16 логических CPU**, доступный parallelism 16; **30.74 GiB RAM**. Машина занята другими процессами; при первоначальной проверке доступно около 6.3 GiB RAM и swap почти заполнен.
- Node.js 24.17.0, pnpm 12.3.4; зависимости закреплены lockfile.
- Playwright 1.63.0: Chromium 153.0.8010.12 и **Firefox 155.0**, headless. Firefox установлен из официального Playwright download (Ubuntu 24.04 fallback для Fedora).
- Production-сборка Vite, статический localhost preview; настоящие IndexedDB и service worker. Фиксированная дата основного сценария: 2026-10-05, Europe/Moscow. Профили изолированы, без подмены хранилища.

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium firefox
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test:browser --workers=2
pnpm exec playwright test --config playwright.acceptance.config.ts
```

Сборки/браузерные наборы выполняйте последовательно в одном checkout: каждый собирает production-оболочку. Публичные тесты используют исключительно синтетические данные. `playwright.acceptance.config.ts` отключает screenshots, video и trace; приватная приёмка выполнялась отдельным standalone runner вне репозитория, без test reporter, console capture, скриншотов, HAR или trace.

## Результаты

- Статические проверки: TypeScript, ESLint, Prettier и `git diff --check` пройдены.
- Основной Chromium-набор: **133 теста**, включая CRUD, черновики, списки, порядок, реальные pointer-переносы, клавиатурные команды, независимость чек-листа и выполнения, настройки, календарные границы/timezone, поиск и пагинацию, CSV-валидацию, атомарность и полное восстановление.
- Отдельная нагрузочная сквозная приёмка: **2 сценария пройдены**, Chromium и Firefox. Каждый импортирует 16 650 синтетических записей, планирует неделю, меняет заметку/цвет/чек-лист, порядок и размещение, ищет, закрывает профиль и открывает его офлайн на 360 px, выполняет офлайн операции и переносит полный backup в другой чистый профиль. Повтор CSV после восстановления добавляет ноль.
- Офлайн в обоих движках проверены просмотр, создание, редактирование заметки и чек-листа, выполнение, перенос день → список, порядок, удаление, управление списками, поиск, CSV-импорт, скачивание JSON и восстановление. После возврата сети/перезагрузки данные совпадают.
- Обновление/ошибка установки оболочки проверены отдельными Chromium-тестами: готовность только после полного кэширования, старый кэш при неудаче, успешное обновление без потери задач и без перезагрузки открытого черновика.
- Сравнение скачанных копий включает все задачи, ID, размещение, порядок, настройки, списки, чек-листы, цвета и историю импортов; исключается только `exportedAt`.
- На 1440 px подтверждены семь колонок; на 360 px семь дней/списки доступны без горизонтального скролла. Основные действия активируются Enter/Space; editor trap/возврат фокуса, подписи и touch-размеры проверены тестами. Файлы и некоторые значения полей подаются через публичные browser automation controls, не через внутренние функции базы.
- Script-подобный текст остаётся текстом, URL из задачи/заметки не загружается. В контролируемом сценарии локальных операций после загрузки оболочки: **0 сетевых запросов**. В сборке только HTML/CSS/JS, service worker и лицензии; личные файлы не включены.

## Настоящая выгрузка: только агрегаты

Оригинальный локальный файл **существует** и был проверен отдельно через UI, не как публичная фикстура. В обоих движках подтверждены:

- 794 363 байта, 16 650 задач, 2 выполненные / 16 648 невыполненных.
- Даты 2026-10-01 — 2040-01-01; 13 повторных вхождений сохранены отдельными ID.
- Одна непустая заметка, 3 408 Unicode-символов, без сокращения или интерпретации.
- Все шесть исходных CSV-полей **каждой записи**, рабочие поля, размещение, порядок внутри даты, номер исходной логической записи и SHA-256 происхождения сверены со скачанным backup.
- Импорт не переключил текущую неделю в 2040 год.
- Закрытие/повторное открытие исходного профиля без сети сохранило полную копию.
- Другой чистый профиль получил полное совпадающее восстановление офлайн; повтор исходных байтов добавил **0 задач**, повторный backup совпал.
- За импортом и первым скачиванием наблюдалось 0 сетевых запросов. Приватные профили и скачивания очищены после проверки; содержимое задач/полей, отпечаток файла и изображения не записаны в отчёт или репозиторий.

Последний приватный прогон включая выбор файла/preview: Chromium 1 147 ms, Firefox 1 247 ms (не основной замер порога после подтверждения).

## Исправленные проблемы

- CSV-preview явно объясняет невозможность восстановить отсутствующие списки и отсутствие новых повторных вхождений после последней даты. Новая UI-регрессия сначала падала, затем прошла.
- После сохранения редактора из поиска фокус возвращается к обновлённому результату (или к полю поиска, если результата больше нет). UI-регрессия сначала выявила потерю фокуса и прошла после исправления.
- Offline-тесты использовали первый textbox, ставший полем даты после интеграции навигации; теперь находят быстрый ввод по доступной подписи.
- Межконтейнерный тест drag не генерировал `dragstart` после прокрутки. Настоящий пошаговый pointer-жест начинает drag до прокрутки к цели; все positional/append-проверки и повторное открытие проходят. Логика приложения не была изменена ради теста.
- Удалены гонки нового интеграционного runner: перед клавиатурным действием ожидается доступность элемента, перед сравнением/перезапуском — наблюдаемый результат записи. Сравнение больших копий не выполняет десятки тысяч отдельных Playwright assertions.
- MIT и полный Papa Parse notice включены в `dist/`; README и публичные контракты дополнены.

## Проверка исправлений финального review

База исправлений: `eb16cba`, 2026-10-06. Все четыре spec-finding и оба standards-finding исправлены; прежние числа и приватные агрегаты выше — результаты предыдущей приёмки, а не повторного полного прогона.

- Spec 1: нейтральный цвет хранится без свойства `color`; экспорт также удаляет только внутреннее `color: undefined` из копии старых записей, не меняя базу. Внешний JSON по-прежнему строго отклоняет null/неизвестные цвета/некорректные optional-поля. [UI download/restore](../tests/review-fixes.spec.ts), [строгая валидация](../tests/review-domain.spec.ts).
- Spec 2: whitespace-only пункт отклоняется редактором с видимой ошибкой и сохранённым черновиком, а также публичным storage API. Непустой текст сохраняется буквально, включая крайние пробелы и переносы строк. Старые некорректные пункты не удаляются и не переписываются: экспорт называет задачу/номер пункта и предлагает исправить его в редакторе. [Регрессия сохранности старой базы и исправления](../tests/review-legacy.spec.ts), [storage invariant](../tests/csv-storage.spec.ts).
- Spec 3: фокус запоминается до disabling, возвращается на перемещённую кнопку после rerender либо на название задачи у границы; после abort — на исходную кнопку. Настоящие Enter-проверки обоих направлений включают следующий keyboard action и порядок задач. [Keyboard-регрессии](../tests/review-fixes.spec.ts).
- Spec 4: завершённый CSV-отчёт содержит задачи, фактически созданные списки и пустые записи. Проверены повторное использование списка, создание списка другой вкладкой после preview и повтор тех же байтов (0 задач / 0 новых списков). [CSV completion-регрессия](../tests/review-fixes.spec.ts).
- Standards 1: единый UTC calendar-date predicate используется CSV и placement, а backup сохраняет свои структурные проверки. Год 0000, неверный формат/месяц/день и невисокосные даты отклоняются; 2044/2400-02-29, 0099 и 9999 принимаются. [14 публичных domain-проверок](../tests/review-domain.spec.ts) также прошли с `TZ=Pacific/Kiritimati`.
- Standards 2: только маленький конструктор title/defaults/placement/append-order общий для задач дня и списка; разные IndexedDB lookup/transaction пути сохранены. [Проверка обоих public creation API](../tests/csv-storage.spec.ts).

Red → green: до исправлений UI не скачивал JSON после обычной правки, закрывал whitespace-черновик без ошибки, терял фокус в обоих направлениях и после abort, а CSV не показывал число списков. Дополнительные red-проверки выявили принятие года 0000 и неинформативную ошибку старого чек-листа. Первоначальное trimming исправления нарушило существующую проверку буквального текста; финальная версия отклоняет пустые пункты без trimming валидного текста.

## Непроверенное и ограничения

- **Native Safari недоступен на Linux и не проверен.** Playwright WebKit не удалось запустить из-за отсутствующего executable и не выдаётся за Safari. Нужен Safari smoke на macOS/iOS: повторное открытие, импорт, восстановление и офлайн.
- Физические мобильные устройства и настоящий screen reader не проверялись; размеры viewport/доступные имена/keyboard focus не заменяют такой аудит.
- Реальное исчерпание дисковой/browser quota не принуждалось: переносимое управление quota в этом окружении не подтверждено. Пройдены реальные abort/error транзакций после queued/request-success writes для задач, порядка, списков, CSV и восстановления; это доказательство атомарности/ошибок, **не утверждение о проверенной quota enforcement**.
- Референсная машина 4 CPU/8 GiB, размещение в подкаталоге и optional dependency binaries других ОС не проверены. Поддерживаемая инструкция размещения — корень HTTPS-сайта или стабильный localhost.
- Данные привязаны к origin/профилю; одна рабочая вкладка. Browser eviction/очистка и private mode не дают долговременных гарантий. Постоянное хранение не заменяет backup.
- CSV не восстанавливает recurrence, отсутствующие списки, цвет или неподтверждённый непустой Checklist. Новых автоматических вхождений после последней даты нет. MIT собственного кода не распространяется на личные исходные файлы.
